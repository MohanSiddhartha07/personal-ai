* Broadcasting fundamentals

### Important Learning Notes

`np.random.seed()` controls the starting point of NumPy's pseudo-random number generation so that random results can be reproduced.

For example:

```python
np.random.seed(42)
```

The number `42` is not special. Another integer can be used.

## Learning Philosophy

I learn best by building practical projects.

I should avoid spending excessive time learning frameworks without understanding the underlying concepts.

For AI projects, I want to understand the underlying architecture before relying heavily on abstractions or frameworks.

When learning a new concept, I should preferably:

1. Understand the problem.
2. Build a simple version.
3. Understand why it works.
4. Experiment with it.
5. Then introduce frameworks or more advanced implementations.
